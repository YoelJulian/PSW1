1.Mengapa telepon bukan kuantitas number?
    telepon bukan kuantitas number, karena telepon mengandung tanda "+" yang berupa char bukan number
2.Apa beda label pilihan dan legend kelompok
    label membuat input pada kotak text dan checkbox yang ada penjelasnya, sedangkan legend langusng memberi keterangan pada pilihan dalam "<fieldset>"
3.apa beda id dan name
    id adalah penghubung untuk input, sedangkan name adalah nama data dan pengenal pada form
4.apa yang terjadi pada checkbox tidak dicentang?
    form akan tetap terisi, tetapi checkbox tidak akan memiliki
